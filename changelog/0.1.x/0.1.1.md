# 0.1.1 — 2026-09-26

## Added

- **`PdfOptions.maxTextItems`, `maxTextChars`, `maxOperators`** (defaults 500,000, 4,000,000, and 10,000,000), which `parse()` forwards: document-wide PDF reading budgets. Reading stops at the first one reached, keeps what was read, and warns `truncated-input` ([#6](https://github.com/cyanheads/scholarly-parse/issues/6)).
- **`toSections` ends with a `floats` entry** holding `document.floats` under Figures and tables, when there are any ([#18](https://github.com/cyanheads/scholarly-parse/issues/18)). `FlatSection.kind` gains `'floats'`.

## Changed

- **A PDF page that fails to load** ends reading with a `truncated-input` warning and keeps the pages before it, instead of failing the parse as `malformed`; with no usable text before it, the result is still `malformed`.
- **Grobid TEI outline**: numbered list items Grobid writes as headings nest as paragraph headings of the section they interrupt ([#16](https://github.com/cyanheads/scholarly-parse/issues/16)), and an unnumbered heading nests under the numbered section before it, numbered `2` or `2.` ([#19](https://github.com/cyanheads/scholarly-parse/issues/19)). Section structure changes for some Grobid documents.

## Fixed

- **`toText`** leaves code and TeX as written (code spans and blocks, inline and display math) and drops code fence lines; quote markers come off at every depth ([#15](https://github.com/cyanheads/scholarly-parse/issues/15)).
- **`toMarkdown({ sections })`** renders every ID `toSections` returns, `abstract-N` and `floats` included ([#21](https://github.com/cyanheads/scholarly-parse/issues/21)).
- **Reference DOIs** in PDF, HTML, and LaTeXML leave out closing punctuation and enclosing quotes or brackets, keep balanced parentheses in the suffix, and are read when quoted ([#22](https://github.com/cyanheads/scholarly-parse/issues/22), [#25](https://github.com/cyanheads/scholarly-parse/issues/25)).
- **Document-sized lists** are appended in a loop, so a section holding a very large number of blocks parses instead of failing as `malformed` ([#14](https://github.com/cyanheads/scholarly-parse/issues/14)).
- **JATS and TEI character references** to U+0000, a surrogate, or past U+10FFFF read as U+FFFD, as in HTML and LaTeXML, and the entity-expansion cap counts only DOCTYPE-declared entities, so an article dense with `&amp;` parses ([#12](https://github.com/cyanheads/scholarly-parse/issues/12)).
- **One-page PDF reads** keep the lines in the top and bottom margins, dropping only a page number ([#20](https://github.com/cyanheads/scholarly-parse/issues/20)).
- **PDF table cells** right of every column land in the last column rather than the first.
- **Grobid TEI text**: sentences in adjacent `<s>` elements and caption paragraphs are spaced, keywords Grobid could not split stay one keyword, and OpenAlex's HTML-wrapped TEI reads the `<back>` beside `<text>`.
- **Grobid TEI sections**: a heading with no text of its own is kept when sections follow it, including a back-matter statement Grobid writes entirely as a heading, and figures and tables beside annex parts are floats.

## Security

- **`parsePdf` bounds pdf.js work across the document** through the new reading budgets. One page's own pdf.js work stays unbounded, so a hard time or memory bound on untrusted PDFs needs a worker or process the caller can terminate.
- **Table grids draw on one budget per document** in every format: copies of a spanned cell past 1,000,000 characters are left empty and rows past 2,000,000 grid cells dropped, each cut table warned `truncated-input` ([#8](https://github.com/cyanheads/scholarly-parse/issues/8)). PDF grids draw on the same cell budget.
- **Markdown nests lists, quotes, and boxes at most eight levels**; deeper content renders at the eighth level's prefix, so output size and stack depth stay bounded ([#11](https://github.com/cyanheads/scholarly-parse/issues/11)).
- **Text patterns run in linear time on hostile input**: the HTML interstitial check, TeX delimiters, DOI and trailing-punctuation trims, arXiv links, LaTeXML watermarks and listings, JATS citations, emphasis, and `toText` ([#9](https://github.com/cyanheads/scholarly-parse/issues/9)).
- **TEI affiliations** are indexed as they are read, so an author list with many distinct affiliations parses in linear time (the TEI part of [#10](https://github.com/cyanheads/scholarly-parse/issues/10)).
