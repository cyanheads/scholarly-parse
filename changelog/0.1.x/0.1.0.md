# 0.1.0 — 2026-09-26

## Added

- **`ScholarlyDocument`** — the document model every parser produces: front matter, abstracts by kind, a section tree of typed blocks (paragraph, list, table, figure, formula, code, quote, box, supplement), references, footnotes, floats, and `diagnostics` with a `quality` of `structured`, `partial`, or `flat`.
- **`ParseResult`** — parsers return `{ ok: true, document }` or `{ ok: false, error: { reason, message } }`, with reasons `malformed`, `wrong-format`, `empty`, `blocked`, and `too-large`.
