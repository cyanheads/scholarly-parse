# 0.2.3 — 2026-11-15

## Changed

- **Dev tooling**: `devcheck` runs the suite on Node as well as Bun and the packed package on Node, Bun, and `workerd` (`test:package`) ([#70](https://github.com/cyanheads/scholarly-parse/issues/70)); the corpus gains fused-text, `toText`-markup, and dropped-float invariants ([#67](https://github.com/cyanheads/scholarly-parse/issues/67)) and a `pmc-oai` fixture kind ([#51](https://github.com/cyanheads/scholarly-parse/issues/51)).

## Fixed

- **`parsePdf`** under pdf.js 6 (`unpdf` ≥1.9) asks for font names, so bold, italic, and math runs are no longer lost.
- **`parsePdf`** keeps a table captioned in another language (`TABEL 1`, `Tabla 1`, `Tabelle 1`; figures as `Abb.`, `Figura`, …) as a table or figure, and continues a caption whose lines are centred under a label set alone on its line ([#88](https://github.com/cyanheads/scholarly-parse/issues/88)).
- **`parsePdf`** reads a table set across both columns whole instead of splitting it at the gutter, and keeps a wrapped cell's next line in its cell ([#49](https://github.com/cyanheads/scholarly-parse/issues/49)).
- **`parsePdf`** keeps superscripts, subscripts, and italics in the title ([#85](https://github.com/cyanheads/scholarly-parse/issues/85)).
- **`parsePdf`** keeps superscripts, subscripts, and italics in section headings, and reads a wrapped bold heading whole when its quote marks are set in a regular face or it opens with a lower-case symbol (`m6A`, `mTOR`) ([#84](https://github.com/cyanheads/scholarly-parse/issues/84)).
- **`parsePdf`** reads prose with no heading before the reference list as an untitled opening section instead of dropping it as front matter.
- **`parseHtml`** returns `blocked` for an HTTP error page whose status line has inline markup, an IIS reason (`404 - File or directory not found.`), or a `HTTP Status ` or `Error ` prefix ([#87](https://github.com/cyanheads/scholarly-parse/issues/87)).
- **`parseHtml`** keeps the declarations a bioRxiv or medRxiv landing page sets as headings after the abstract as sections, and skips "back to top" links as page furniture ([#30](https://github.com/cyanheads/scholarly-parse/issues/30)).
- **`parseTei`** reads an abstract Grobid writes as a `<head>` with no text after it, instead of returning none.
- **`parseJats`** reads the `<aff>`, `<xref>`, and `<email>` inside a `<collab>` into the group's author record, and no longer spells them into its name.
