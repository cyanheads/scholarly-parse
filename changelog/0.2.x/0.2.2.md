# 0.2.2 — 2026-10-17

## Added

- **`parsed()`** fills an empty `arxiv` on `metadata.identifiers` and on each reference from an arXiv DataCite DOI (`10.48550/arXiv.2105.00001` → `2105.00001`), on a copy, so the document passed in is unchanged ([#76](https://github.com/cyanheads/scholarly-parse/issues/76)). An ID the source types, prints, or links always wins.

## Changed

- **Table footers** (`<tfoot>`, `ltx_tfoot`) come after every body row, as HTML shows them; a JATS `<tfoot>` written before `<tbody>` no longer reads above it ([#81](https://github.com/cyanheads/scholarly-parse/issues/81)).
- **`blocked`** now also covers an HTML page whose `<title>` or `<h1>` is a 4xx or 5xx status line alone, such as `404 Not Found` ([#64](https://github.com/cyanheads/scholarly-parse/issues/64)).

## Fixed

- **JATS references** read an arXiv ID from an `ext-link-type="arxiv"` link or an arxiv.org `<ext-link>` or `<uri>`; an untyped link stays `url` unless a DOI is held ([#75](https://github.com/cyanheads/scholarly-parse/issues/75)).
- **TEI references** read an arXiv ID from an arxiv.org `<ptr target>`, after a typed `<idno>` ([#79](https://github.com/cyanheads/scholarly-parse/issues/79)).
- **JATS `<citation-alternatives>`** takes identifiers the `<element-citation>` leaves empty from the `<mixed-citation>` ([#80](https://github.com/cyanheads/scholarly-parse/issues/80)).
- **Table rowspans** end with their row group (`<thead>`, `<tbody>`, `<tfoot>`, their `ltx_` classes, and each run of bare rows) instead of shifting the next group's cells; `rowspan="0"` covers the rest of its group ([#46](https://github.com/cyanheads/scholarly-parse/issues/46)).
- **`parseHtml`** fails arXiv's "No HTML" page as `empty`, as `parseLatexml` does ([#64](https://github.com/cyanheads/scholarly-parse/issues/64)), and its page for an ID with no paper or a withdrawn version as `empty` ([#86](https://github.com/cyanheads/scholarly-parse/issues/86)).
- **`parseHtml`** no longer spends section IDs or warnings on bold-labelled parts it then discards ([#54](https://github.com/cyanheads/scholarly-parse/issues/54)).
- **Subscript `_`** is escaped where it could open or close emphasis (`*k*\_1`, `a \_2`, `y\_{ab}`); one between letters or digits (`H_2O`) stays ([#77](https://github.com/cyanheads/scholarly-parse/issues/77)).
- **PDF**: a first-page margin column, such as a sidebar of editors beside the abstract, is read apart from the abstract ([#4](https://github.com/cyanheads/scholarly-parse/issues/4)).
- **PDF**: rows are assembled on each side of the column gutter, so a footnote line or superscript level with a row in the other column no longer joins it ([#47](https://github.com/cyanheads/scholarly-parse/issues/47)).
- **PDF**: a run whose advance contradicts its reported size no longer sets its row's baseline or its line's size ([#48](https://github.com/cyanheads/scholarly-parse/issues/48)).
- **PDF**: a raised prime or exponent stays on its formula and a subscript stays on its letter beside tall delimiters, and a condensed bold heading keeps its size beside a raised footnote mark.
- **PDF**: unnumbered reference lists split at the indent their first line sets, hanging or first-line, and at their own entry gaps when set closer than the body ([#50](https://github.com/cyanheads/scholarly-parse/issues/50)).
- **PDF**: a running footer whose page number sits on either half is dropped on every page ([#83](https://github.com/cyanheads/scholarly-parse/issues/83)).
- **PDF**: a bold label or heading split by a ligature or apostrophe set in a regular font reads whole, so back matter ends the reference list ([#82](https://github.com/cyanheads/scholarly-parse/issues/82), [#84](https://github.com/cyanheads/scholarly-parse/issues/84) in part).
